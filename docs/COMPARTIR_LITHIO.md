## Mensaje completo para WhatsApp

```

El moto-taxi de la universidad: pide tu viaje, paga con Iones Li⁺ y gana Fe.

📲 *Descárgalo aquí:* https://lithio-api-production.up.railway.app/descargar

*Cómo instalarlo (2 min):*
1️⃣ Toca *Descargar LITHIO*. Si Chrome avisa, toca *Descargar de todas formas*.
2️⃣ Abre el archivo (o búscalo en *Archivos → Descargas*).
3️⃣ Si dice *"Instalación bloqueada"* u *"origen desconocido"*:
     toca *Configuración* → activa *Permitir desde esta fuente* → vuelve *atrás* → *Instalar*.
4️⃣ Si sale *Play Protect* o *"App no segura"*:
     toca *Más detalles* → *Instalar de todas formas*. ⚠️ No toques "Aceptar".
5️⃣ ¡Listo! Ábrela, entra con Google o tu correo y activa las notificaciones.

ℹ️ Los avisos salen porque aún no está en Play Store: es normal y es seguro si lo bajas de este link.
🍏 ¿iPhone? Abre el mismo link en Safari y toca *Usa la versión web*.
```

## Si alguien se traba con un aviso

**«Por tu seguridad, el teléfono no puede instalar apps desconocidas de esta fuente»**
```
Toca *Configuración* en ese aviso, activa *Permitir desde esta fuente*, vuelve atrás y toca *Instalar*.
Si no sale el botón: Ajustes → Apps → Chrome → Instalar apps desconocidas → Permitir.
(Samsung: Ajustes → Aplicaciones → Chrome → Instalar aplicaciones desconocidas)
```

**«App bloqueada para proteger tu dispositivo» / «Play Protect no reconoce al desarrollador»**
```
Toca *Más detalles* (la flechita) y luego *Instalar de todas formas*.
En algunos teléfonos dice *Instalar sin analizar*. No toques "Aceptar", que cancela.
```

**«No se instaló la app» / «Error al analizar el paquete»**
```
La descarga quedó incompleta. Borra LITHIO.apk de Descargas y bájalo otra vez con buena señal.
```

**Xiaomi, Redmi o POCO**
```
Espera la cuenta regresiva, marca "Soy consciente de los riesgos" y toca Instalar.
```
